**核心信息**: 业界首个行为链级Agent安全治理平台

**产品定位**: 多智能体工具调用行为链风险治理系统

4. **MCP协议安全** — 工具投毒/影子/Rug Pull/影子服务器检测

**视觉建议**: 四层架构图（应用接入层 -> MCP安全层 -> 行为链治理层 -> 数据评测层）

### 第4页：技术亮点

**核心信息**: 五项核心技术创新，完整专利保护

**亮点1: 行为链风险传播模型**
- 有向图建模 + 贝叶斯传播算法
- 公式：R(i) = alpha*L(i) + beta*I(i) + gamma*A(i)
- 反向BFS实现风险累积计算

**亮点2: 硬门控实时阻断**
- 三级门控：ALLOW / HUMAN_REVIEW / BLOCK
- 未来分支投影：模拟阻断后的可能后果
- 反事实分析：回答"如果允许会怎样"

**亮点3: MCP协议安全检测**
- 无状态验证器（ToolValidator）：结构/语义/安全多层次验证
- 有状态检测器（MCPDetector）：投毒/影子/Rug Pull/影子服务器
- 风险放大建模：每步23-41%放大系数

**亮点4: 半真实Trace Benchmark**
- 真实Agent调用模式 + 合成风险注入
- 9类场景模板，150条Trace，405个步骤
- 业界首个Agent行为链安全标准化评测

**亮点5: 多Agent级联防御**
- 跨Agent风险追踪（横向/纵向/回环传播）
- SHA-256防篡改审计链
- 统一审计视图

**视觉建议**: 行为链风险传播示意图（节点+边+风险值标注）
