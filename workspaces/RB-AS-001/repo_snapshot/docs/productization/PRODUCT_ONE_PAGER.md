# AgentShield V3 — 产品一页纸

## 产品定位

**多智能体工具调用行为链风险治理系统**

在多Agent协作场景中，Agent通过工具调用（Tool Use）执行任务时，单步风险可能沿行为链传播放大。AgentShield提供行为链建模、风险传播分析、硬门控阻断和全链路审计能力，确保Agent系统安全可控。

## 核心问题

| 问题 | 描述 | AgentShield方案 |
|------|------|----------------|
| 风险传播 | 单步工具调用的风险沿链路放大 | 行为链风险传播模型 |
| 不可控执行 | Agent越权调用高危工具 | 硬门控（Hard Gate）机制 |
| 审计缺失 | 无法追溯Agent决策过程 | 全链路审计日志 |
| 评估困难 | 缺乏真实场景benchmark | 半真实Trace Benchmark（V3.1） |

## 技术亮点

1. **行为链建模** — 将Agent工具调用序列建模为有向图，支持分支、并行、回环
2. **风险传播引擎** — 基于贝叶斯网络的风险传播计算，支持实时风险评估
3. **硬门控机制** — 在工具调用前进行风险阈值检查，超阈值自动阻断
4. **半真实Trace Benchmark** — V3.1引入真实Agent调用数据+合成风险注入的评测框架
5. **多Agent协同审计** — 支持多Agent系统的统一审计视图
