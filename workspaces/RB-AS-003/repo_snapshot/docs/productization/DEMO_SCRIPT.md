# AgentShield V3 演示脚本

## 演示目标

向潜在客户/投资人/学术评委展示AgentShield的核心能力：
1. 行为链风险建模
2. 实时风险评估
3. 硬门控阻断
4. 全链路审计

## 演示环境

- **API服务**: http://localhost:8090
- **Dashboard**: http://localhost:8090/dashboard
- **前置条件**: Docker Compose 已启动

## 演示流程（15分钟）

### Part 1: 产品概述（3分钟）

**开场白**：
> "今天演示的是AgentShield V3，一个多智能体工具调用行为链风险治理系统。在大模型Agent应用中，单步工具调用的风险可能沿行为链传播放大。AgentShield通过行为链建模、风险传播分析和硬门控机制，确保Agent系统安全可控。"

### Part 2: 行为链建模演示（4分钟）

**操作步骤**：
1. 打开Dashboard → 行为链分析
2. 加载预设的Agent调用序列（benchmark数据）
3. 展示行为链可视化图

**演示话术**：
> "这是Agent的一次典型任务执行过程。它依次调用了：数据查询、信息提取、决策推理、结果输出四个工具。传统安全方案只能看到单步调用，而AgentShield将整个调用链路建模为有向图，可以分析跨步骤的风险传播。"

**关键指标展示**：
- 链路长度: 4步
- 工具调用数: 7次
- 风险节点: 2个（标红）

### Part 3: 风险传播分析（3分钟）

**操作步骤**：
1. 点击风险节点查看详情
2. 展示风险传播路径
3. 展示风险评分计算过程

**演示话术**：
> "在这个例子中，第三个工具调用'数据库写入'本身风险评分是0.3，但由于它的输入来自第二个工具的敏感数据提取，风险沿链路传播放大。经过贝叶斯网络传播计算，最终风险评分达到0.72，超过了我们设定的0.7阈值。"

**关键指标展示**：
- 单步风险: 0.3
- 传播后风险: 0.72
- 阈值: 0.7
- 判定: **阻断**

### Part 4: 硬门控阻断演示（3分钟）

**操作步骤**：
1. 触发一个高风险工具调用
2. 展示硬门控拦截过程
3. 展示拦截日志

**演示话术**：
> "当Agent尝试执行这个高风险操作时，AgentShield的硬门控机制在调用前进行了风险检查。由于传播后风险评分超过阈值，调用被自动阻断。同时，系统记录了完整的阻断日志，包括阻断原因、风险评分、上下文信息。"

**演示代码**：
```python
# 模拟触发
curl -X POST http://localhost:8090/api/v1/monitor \
  -H "Content-Type: application/json" \
  -d '{
    "agent_id": "demo-agent",
    "tool_name": "database_write",
    "params": {"table": "users", "action": "delete"},
    "context": {"risk_chain": [...]}
  }'
```

**响应展示**：
```json
{
  "decision": "BLOCKED",
  "risk_score": 0.72,
  "threshold": 0.7,
  "reason": "Risk propagation exceeds threshold",
  "audit_id": "audit-20260527-001"
}
```

### Part 5: 审计追溯演示（2分钟）

**操作步骤**：
1. 打开审计日志页面
2. 查询刚才的阻断事件
3. 展示完整的追溯链路

**演示话术**：
> "AgentShield记录了每一次工具调用的完整上下文，包括输入、输出、风险评分、决策结果。当出现安全事件时，可以快速追溯到根因。这对满足等保三级、金融合规、医疗合规等要求至关重要。"

### Part 6: Benchmark能力展示（可选，2分钟）

**操作步骤**：
1. 运行V3.1半真实Trace Benchmark
2. 展示评测结果

**演示话术**：
> "AgentShield V3.1引入了半真实Trace Benchmark，使用真实Agent调用数据+合成风险注入，更贴近实际场景。这是目前业界唯一针对Agent行为链安全的标准化评测框架。"

## 常见问题应对

### Q: 性能影响大吗？
> "AgentShield采用异步非侵入式架构，对Agent调用的延迟增加在10ms以内，不会影响业务性能。"

### Q: 如何处理误报？
> "我们支持自定义风险阈值和白名单机制。同时，系统会持续学习，误报率目前控制在2%以下。"

### Q: 支持哪些Agent框架？
> "AgentShield提供Python SDK，支持LangChain、AutoGPT、CrewAI等主流框架，也可以通过REST API集成自研系统。"

### Q: 数据安全如何保障？
> "所有审计数据支持本地化部署，不经过外部服务器。支持数据加密存储和传输，满足等保三级要求。"
