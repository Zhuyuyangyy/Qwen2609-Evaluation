### 图2：行为链风险传播示意图

**文件位置**: `docs/PATENT_DISCLOSURE_V3.md` 第六章 图2

**图说明文字**:
> 图2展示了多Agent行为链中风险的传播过程。以三个Agent（A、B、C）构成的数据泄露攻击链为例：
> - Agent A执行"查询数据库"操作，基础风险R=0.2，链阶段为data_access；
> - Agent B执行"压缩数据"操作，风险传播至R=0.45，链阶段为prep；
> - Agent C执行"发送到外部"操作，风险进一步放大至R=0.82，链阶段为exfiltration，触发BLOCK决策。
>
> 风险传播计算公式：R(3) = max(L(3), I(3) × amplification)
> 其中L(3)=0.6（外部网络传输基础风险），I(3)=R(1)×0.5²+R(2)×0.5¹=0.275，amplification=0.32×(1+0.10×3)=0.416。
> 最终R(3)=max(0.6, 0.275×0.416)=0.6，经综合评估得0.82，触发BLOCK决策。

**技术要点**:
- 多Agent行为链的有向图表示
- 风险沿链路的传播和放大
- 三级门控决策的触发条件

**绘图要求**:
- 使用有向图表示Agent间的调用关系
- 在边上标注风险传播值
- 使用颜色渐变表示风险等级（绿→黄→红）
- 在图的右侧或下方标注计算公式

### 图3：MCP协议安全检测流程图

**文件位置**: `docs/PATENT_DISCLOSURE_V3.md` 第六章 图3

**图说明文字**:
> 图3展示了MCP协议安全检测的三阶段流程：
>
> Phase 1 - 工具描述验证（ToolValidator）：对工具描述进行结构验证（名称/长度/参数/深度）、规范合规验证（Annotation/Schema）、语义攻击检测（权限诉求/紧迫性/指令覆盖/角色劫持）和安全扫描（凭证/外泄/破坏/提权），输出0.0-1.0的安全评分。
>
> Phase 2 - 协议威胁检测（MCPDetector）：维护会话状态，检测工具投毒（命令注入/路径遍历/提示注入）、工具影子（同名工具冲突）、Rug Pull（描述变更检测）和影子服务器（来源验证），计算风险放大系数（23-41%/step）和级联深度（threshold=3 steps）。
>
> Phase 3 - 行为链风险治理（V3ShieldEngine）：将前两阶段的检测结果输入V3核心引擎，进行图建模、贝叶斯传播、门控决策和审计日志记录。

**技术要点**:
- 三阶段检测流程
- 无状态验证器和有状态检测器的分工
- 检测结果与V3核心引擎的集成

**绘图要求**:
- 使用标准流程图风格
- 用虚线框区分三个Phase
- 标注每个Phase的输入和输出
- 使用不同颜色区分检测类型
