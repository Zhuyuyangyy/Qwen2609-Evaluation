# AgentShield V3.3 — 一图看懂

## 多智能体行为链安全治理平台

---

### 一句话定位

**AgentShield** 是业界首个面向多智能体工具调用行为链的风险治理与协议安全检测系统，让每一个Agent工具调用都安全可控。

---

### 解决什么问题？

当AI Agent通过工具调用执行任务时，单步风险可能沿行为链传播放大：

```
[数据库查询] --> [数据压缩] --> [发送到外部]
   风险0.2        风险0.45        风险0.82 --> BLOCK!
```

传统方案只能看到单步调用，AgentShield能看到整条链路。

---

### 核心能力

| 能力 | 说明 |
|------|------|
| 行为链建模 | 工具调用序列 -> 有向图，支持分支/并行/回环 |
| 风险传播引擎 | 贝叶斯网络量化风险沿链路的传播放大 |
| 硬门控阻断 | 调用前检查，三级决策：允许/人工审核/阻断 |
| MCP协议安全 | 工具投毒/影子/Rug Pull/影子服务器检测 |
| 全链路审计 | SHA-256防篡改审计链，完整追溯能力 |
